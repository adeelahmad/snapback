# v0.1 acceptance report

This report tracks every SPEC §20 item for the v0.1 release candidate (SPEC §22.1).
A row says "implemented and tested" only when committed Linux evidence under
`docs/reports/v0.1/linux/` records a pass. Supplementary macOS evidence lives under
`docs/reports/v0.1/macos/`; rows cite it with the date and commit of that run.

## Summary

The Linux acceptance run is recorded. CI run 35720597517 (workflow CI, job "FUSE
integration (linux)") ran the acceptance set at the commit the evidence records,
354ace1, on kernel 6.17.0-1022-azure with fusermount3 3.14.0 and restic 0.19.0
(linux/amd64). Every file in `docs/reports/v0.1/linux/` has status pass: the fixtures,
Acc 1 to 17, and the ensure-link and synthetic performance checks. Acc 2, 12 and 17 are
Linux-only — the macOS runs skipped them for want of inotify and systemd — and they
now have Linux passes. Acc 18 and 19 are outside the v0.1 scope in SPEC §22.1, as is
the on-access performance target.

On that evidence the SPEC §22.1 exit criterion for v0.1, that every SPEC §20 acceptance
test which applies to the v0.1 scope passes on Linux, is met by Acc 1 to 17 and the
fixtures. The performance and platform proof rows stay "implemented but not tested here":
the recorded checks are green on Linux, but the reported numbers and the Linux linkage
check SPEC §20 also asks for are not part of this artifact. The two macOS runs on
2026-09-22 (commits ef8decd and d94a4ff, macFUSE) are supplementary only; macOS is a
separately proven follow-up in SPEC §22.1 and is not claimed for v0.1.
