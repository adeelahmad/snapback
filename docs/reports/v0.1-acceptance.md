# v0.1 acceptance report

This report tracks every SPEC §20 item for the v0.1 release candidate (SPEC §22.1).
A row says "implemented and tested" only when committed Linux evidence under
`docs/reports/v0.1/linux/` records a pass. Supplementary macOS evidence lives under
`docs/reports/v0.1/macos/`; rows cite it with the date and commit of that run.

## Summary

Two macOS acceptance runs are recorded, both with macFUSE and restic 0.19.0 on
2026-09-22. The run at commit ef8decd passed Acc 1, 3 to 11, 13, 15 and 16, the fixtures
and the two performance checks; Acc 2, 12 and 17 need Linux and were skipped; Acc 14
failed in its mount case. After the MNT-3 mount fix, Acc 14 was re-run at commit d94a4ff
and passed. No Linux run is recorded yet, so every row is still pending Linux CI
evidence and the SPEC §22.1 exit criterion, that every item passes on Linux, is not yet met.
