# v0.1 acceptance report

This report tracks every SPEC §20 item for the v0.1 release candidate (SPEC §22.1).
A row says "implemented and tested" only when committed evidence under
`docs/reports/v0.1/` records a pass, and it names the platform, date and commit of that run.

## Summary

One acceptance run is recorded: macOS with macFUSE, 2026-09-22, commit ef8decd,
restic 0.19.0. It passed Acc 1, 3 to 11, 13, 15 and 16, the fixtures and the two
performance checks. Acc 2, 12 and 17 need Linux and were skipped. Acc 14 failed in its
mount case. No Linux run is recorded yet, so the SPEC §22.1 exit criterion, that every
item passes on Linux, is not yet met.
